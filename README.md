# SysLabLearns

A personal, visual lab for learning systems: every concept is a live simulation you can poke, build on, and break.

Two tracks:

- **System Design**: wire components on a canvas, send traffic through them, and watch what fails first.
- **Distributed Protocols**: write node code, and let the simulator and model checker attack it.

Inspired by UW's DSLabs and PRISM's visual learning style. Nothing is copied from either.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Test

```bash
npm test
```
